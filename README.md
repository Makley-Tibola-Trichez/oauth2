# OAuth2 Auth Service (NestJS)

Microserviço de autenticação OAuth2 (Client Credentials) para RPAs e microsserviços internos.
Implementação em NestJS + Prisma + PostgreSQL + Vault, equivalente à versão FastAPI (branch
`oauth2-fastapi`) — mesmo desenho, ferramentas diferentes.

Documentação completa de execução ao final da implementação.
